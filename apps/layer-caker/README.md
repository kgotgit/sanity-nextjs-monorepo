This is a [Next.js](https://nextjs.org) app inside a Turborepo workspace.

It uses [Biome](https://biomejs.dev/) for linting and formatting.

## Getting Started

Run the development server from the monorepo root:

```bash
pnpm dev
```

The app runs at [http://localhost:3000](http://localhost:3000).

## Linting

```bash
pnpm --filter layer-caker lint
pnpm --filter layer-caker lint:fix
```
